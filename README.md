# Далисман × ChatGPT — подключение салона

**Пошаговое руководство для подключения аналитики Далисмана к ChatGPT.**

## Начать

Откройте [START_HERE.md](START_HERE.md) и отправьте ссылку на этот файл в ChatGPT, добавив: **«Проведи меня по этой инструкции, по одному шагу»**.

> Только отправленная ссылка не всегда автоматически запускает сценарий. Если ChatGPT не может открыть файл, скопируйте в чат его содержимое.

Помощник использует **две вкладки браузера**: в первой остаётся разговор, во второй выполняются настройки. На первом шаге **не нажимайте «Новый чат»** в текущей вкладке.

Сервер: `https://elklp.ru/api/mcp`
