# Первый отчёт Далисмана

## Сценарий

1. Если `analytics_catalog` доступен — вызови его. Если нет, попроси во **второй вкладке** выбрать `@Далисман` в новом чате. Не выдавай выдуманный результат.
2. Назови доступные организации. Если организаций несколько, спроси **один раз**, какую выбрать. Если одна — сразу переходи к отчёту.
3. Для выбранной организации используй все доступные филиалы.
4. Вызови `service_dashboard` за `preset=7_days`, `include_today=false`, `metrics=["revenue","records","new"]`.
5. Покажи короткую таблицу: выручка, состоявшиеся записи, новые клиенты; текущий период, предыдущий период и разница. Даты возьми из ответа сервиса.
6. Одним предложением назови самое заметное изменение; по возможности добавь ссылку `report_url`, если она вернулась.
7. Если результата нет или ошибка — скажи, на каком этапе остановились, и процитируй безопасный текст ошибки без личных данных.

## Разъяснения

- «Выручка» в Далисмане — поступления по финансовым операциям за услуги и товары; день операции может отличаться от дня визита.
- «Состоявшиеся записи» — не количество уникальных клиентов; один человек может иметь несколько записей.
- «Новый клиент» — первое посещение в доступной истории организации; при неполной истории показатель может быть неточным.
- Не называй изменения причиной чего-либо без подтверждения.
