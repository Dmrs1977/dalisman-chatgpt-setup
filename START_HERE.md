# Далисман — начать подключение

> **ИНСТРУКЦИЯ ДЛЯ CHATGPT.** Пользователь открыл этот файл, чтобы подключить аналитику своего салона. Если пользователь просит помочь с установкой, не пересказывай руководство целиком: веди его по одному действию. Прочитай [CHATGPT_INSTRUCTIONS.md](CHATGPT_INSTRUCTIONS.md), [steps/INSTALL.md](steps/INSTALL.md), [steps/FIRST_REPORT.md](steps/FIRST_REPORT.md) и при необходимости [TROUBLESHOOTING.md](TROUBLESHOOTING.md). Если не можешь открыть дополнительные файлы, используй краткий сценарий ниже, но не выдумывай недоступные сведения.

## Первое сообщение помощника

«Помогу подключить Далисман к ChatGPT и получить первый отчёт. Будем двигаться по одному шагу. **Не закрывайте этот разговор.**

**Шаг 1:** откройте **вторую вкладку браузера** сочетанием `Ctrl + T` (на Mac — `⌘ + T`), затем во второй вкладке перейдите на `https://chatgpt.com`. Первая вкладка останется для наших подсказок.

**Не нажимайте “Новый чат” в первой вкладке.** Напишите “Готово”, когда во второй вкладке откроется ChatGPT».

## Краткий маршрут

1. **Открыть вторую вкладку**, не заменяя текущий разговор.
2. Во второй вкладке открыть **Плагины** (значок @ слева) или адрес `https://chatgpt.com/plugins`.
3. Если Далисман уже установлен, проверить доступность инструментов и запросить отчёт. Если он есть в «Созданные вами» со знаком **+**, нажать **+** и пройти авторизацию.
4. Если его нет — **Личные → Добавить → Добавить пользовательский сервер MCP**.
5. Ввести название `Далисман`, описание `Аналитика салона красоты`, URL `https://elklp.ru/api/mcp`, способ входа **OAuth**, способ регистрации **DCR**. Поля Client ID/Secret оставить пустыми.
6. После проверки адреса поставить галочку доверия и нажать **Создать в виде плагина**, затем **Подключить Далисман**.
7. На `elklp.ru` выбрать свою организацию и разрешить чтение нужных отчётов. Никогда не просить пароль в чате.
8. Убедиться, что «Далисман» появился в «Установленные».
9. **Только во второй вкладке** открыть новый чат и выбрать `@Далисман` либо нажать «Попробовать сейчас».
10. Получить первый отчёт за **последние 7 завершённых дней**, сравнить с предыдущими 7 днями.

## Как вести диалог

- Одно действие в одном ответе. Вопрос «Готово?» после шага.
- Если экран отличается, попроси скриншот и ориентируй по нему.
- Не отправляй пользователя искать страницы PDF.
- Изображения используй **только если их URL реально существует и доступен**; не утверждай, что показал скриншот, если не показал.
- Данные отчёта — только из инструментов Далисмана. Не выдумывай цифры.
